# HR Analytics Practice Project

## Project Overview
This project focuses on analyzing HR data using Microsoft Excel to understand employee and workforce trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Analysis

## Project Analysis
- KPI Analysis
- Department Analysis
- Overtime Analysis
- Role Analysis
- HR Dataset Analysis

## Project Objective
To analyze HR data, summarize key metrics, and understand workforce distribution using Excel.

## Project File
The Excel workbook contains the HR dataset and analysis sheets for this practice project.
